# Contributing to IITD Air Intelligence

Thank you for your interest in contributing to this project!

## How to Contribute
1. Fork the repository.
2. Clone your fork locally.
3. Install dependencies:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```
4. Make your changes in a new branch (`git checkout -b feature-name`).
5. Run tests to ensure nothing is broken:
   ```bash
   pytest tests/
   ```
6. Commit your changes and push to your fork.
7. Submit a Pull Request describing your changes.

## Bug Reports & Feature Requests
If you find a bug or have a feature idea, please open an issue in the GitHub repository.
